Template setup / 模板接入说明

将本目录文件放到 GitHub Pages 发布根目录，编辑 config.js 的 endpoint 为真实 HTTPS 接口；再填写联系人、指定订单、采集告知、页面离开规则。截图路径留空时使用示意图；请只放脱敏后的图片。

请求：POST application/json，不携带 Cookie 或认证信息。后端校验参数、保存数据，以 submissionId 去重；后端记录接收时间。只有后端明确确认保存，页面才显示成功。

HTTP 200
{"code":0,"data":{"submissionId":"与请求中的 submissionId 一致"}}

跨域接口需正确处理 OPTIONS，允许实际 Pages Origin、POST 和 Content-Type。CORS 不是权限控制。前端限制不能替代后端校验；接口未实现，模板不创建数据库。

发布前本地测试：python3 -m http.server 8080 --bind 127.0.0.1。未配置接口时不会发请求；下载 JSON 可查看真实请求结构。到期后关闭后端接收并下线页面。

本模板不加载第三方脚本、统计服务或字体，不实现业务系统计时。业务页面在新标签页打开，用户需返回本页评价，网页无法跨域检测业务步骤是否完成。
